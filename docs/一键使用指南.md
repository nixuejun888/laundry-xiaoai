# 一键使用指南

> 目标：**日常不用记命令**。一个入口（一键中心），所有操作都在菜单里。

## 入口

### 家里 WiFi（首选）

在手机 Termux 里执行（或扫码，二维码由维护者在电脑上生成）：

```bash
python -c "import urllib.request as u;exec(u.urlopen('http://<电脑局域网IP>:8788/oneclick.py',timeout=60).read().decode())"
```

### 外网 / 不在家

```bash
python -c "import urllib.request as u;exec(u.urlopen('https://ghfast.top/https://raw.githubusercontent.com/nixuejun888/laundry-xiaoai/main/tools/oneclick.py',timeout=60).read().decode())"
```

### 全自动模式（不选菜单）

```bash
python ~/laundry-xiaoai/tools/oneclick.py --auto
```

它会：更新工具 → 修复/重启服务 → 缺 token 时引导登录 → 测试播报 → 跑双方案自检。

## 菜单里做什么

| 场景 | 选 |
| --- | --- |
| 日常体检 / 自动修复 | **1** |
| 修复小米登录（token 丢失/无效） | **2** |
| 双方案自检 | **3** |
| 重启服务 | **4** |
| 测试播报 | **5** |
| 切换播报模式（finished/minimal/重要/全部） | **6** |
| 看最近日志 | **7** |
| 停止音箱播放 | **8** |
| 更新本地工具到最新 | **9** |
| 晶御重新授权（方案 B） | **10** |
| 晾衣架联动设置 | **11** |
| 测试晾衣架联动 | **12** |
| 小米 token 一键修复（含重登/固定设备/重启） | **13** |

## 故障对照

- **完全没声音** → 13（先修小米 token）；仍不行看 7 的日志；
- **晶御方案 B 失效** → 10；
- **晾衣架不动** → 12 选 1 只测动作，再 11 重新配置；
- **服务没在跑** → 1 或 4；
- **更新工具** → 9（家里优先局域网源，外网自动用 ghfast 镜像）。
